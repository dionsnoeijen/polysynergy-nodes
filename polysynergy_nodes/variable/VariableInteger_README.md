# Variable Integer

Stores and outputs integer values.

## Inputs

- **Value** (required): Integer value to store

## Outputs

- **Value**: The stored integer value

## Behavior

- Simple passthrough node for integer values
- Stores any integer value (positive, negative, or zero)
- Returns the exact value provided
- Suitable for mathematical operations and numerical workflows

## Example Usage

```
Value: 42
Result: 42
```

```
Value: -15
Result: -15
```

```
Value: 0
Result: 0
```

```
Value: 999999999
Result: 999999999
```
